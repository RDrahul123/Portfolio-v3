GitHub Settings

Connect this back office to your GitHub repository so changes publish directly to your live site.

⚠ About your token: Your GitHub Personal Access Token is stored only in this browser's local storage — it is never sent anywhere except directly to GitHub's API. Use a fine-grained token scoped only to this one repository with Contents: Read and write permission. Do not share this device/browser profile with others, and do not commit your token into any file.
