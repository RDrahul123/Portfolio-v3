About me

Beyond the model.

I work as a Data Science Analyst at Samatrix Consulting, based in Indore, India — and I care about the full lifecycle of a data problem, not just the model in the middle.

WHO I AM

A data scientist and full-stack builder who moves comfortably between notebooks and production code — someone who'd rather ship a working system than polish a slide deck about one.

WHAT I BUILD

Machine learning models, NLP pipelines, and generative AI tools — wrapped in real interfaces (FastAPI backends, dashboards, web apps) that people can actually use, not just demos that live in a notebook.

HOW I THINK

I treat every project as a lifecycle, not a one-off model. Problem framing and data quality matter as much as the algorithm — and a model that isn't deployed or monitored isn't finished.

Problem→ Data→ Experimentation→ Model→ Evaluation→ Deployment→ Monitoring

Process

How I build ML systems.

Every project moves through the same eight stages — scroll to see it activate.

01

Data Collection

Sourcing and validating raw data from APIs, files, or databases.

02

Data Cleaning

Handling missing values, outliers, and inconsistent formats.

03

EDA

Exploring distributions, correlations, and structure before modeling.

04

Feature Engineering

Shaping raw fields into signals a model can actually learn from.

05

Model Training

Selecting and tuning algorithms against the problem, not the trend.

06

Evaluation

Testing against metrics that reflect the real decision being made.

07

Deployment

Wrapping the model in an API or app people can actually use.

08

Monitoring

Watching for drift and failure once it's live, not just at launch.
